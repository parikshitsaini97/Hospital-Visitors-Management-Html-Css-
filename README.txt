Hospital Visitor Management System — HTML + CSS only

Files:
- index.html: page structure and sample visitor information
- style.css: layout, colors, forms, tables, responsive design

How to run:
1. Keep index.html and style.css in the same folder.
2. Double-click index.html to open it in a browser.
3. To edit, open either file in VS Code.

Important limitation:
This is a front-end demonstration. There is no JavaScript or backend, so forms do not save data, search does not filter the table, and exit recording does not change visitor status. Sample records are fictional.
